# Downloaded-file reader compatibility — September 6, 2026

Tested the React Native app at `118b486` on iPhone 17 Pro Max / iOS 26.5 Simulator, using Maestro and visual inspection. No reader implementation was changed during this audit. Nine files imported through the actual iOS Files picker; a tenth, TXT, was rejected without blocking the other imports. The simulator library retains these books.

“Pass” below covers the listed sampled checks, not every page or full format conformance.

## Confirmed gaps and next fixes

1. EPUB image resources: repair local image loading in HTML chapters. The sampled manga cannot be read today.
2. Spine media types and fallbacks: the reader currently calls `readText` for every spine item, including JPEGs. Respect the item's media type and fixed-layout metadata.
3. Preserve safe publication layout: linked stylesheets and SVG are not in the current sanitizer's allowed markup. This is consistent with the blank SVG cover and lost vertical writing. Fix resource loading, CSS, and SVG handling with appropriate local-resource boundaries; do not simply disable sanitization.
4. Import real navigation labels. “Chapter 3 of 15” currently contains Alice's actual Chapter I.
5. Search shows unavailable-chapter indexing warnings after importing this corpus. Image-only spine items must not be treated as failed prose downloads. No claim of PDF/comic OCR search support.

The EPUB evidence is a failure even where a Maestro flow successfully reached a chapter counter. Pixel inspection exposed the broken content. Initial automation retries were necessary for results under the keyboard, offscreen library cards, and navigating the Files folder; those missed taps are not counted as reader failures.

## Sources and reproducibility

Exact URLs, byte sizes, SHA-256 hashes, and CBZ derivations are in [the corpus manifest](2026-09-06-corpus.json). Downloads are retained locally under `outputs/compatibility/downloads/` and ignored by Git. Original downloads are unchanged; the two CBZs are explicitly derived test files, not publisher-provided CBZ releases.

- [Project Gutenberg: Alice's Adventures in Wonderland](https://www.gutenberg.org/ebooks/11) — EPUB and TXT.
- [IDPF EPUB3 samples](https://idpf.github.io/epub3-samples/30/samples.html) — Haruko variants and Kusamakura. Haruko artwork credit: 倉塚りこ. See each sample's publication credits and licensing.
- [Adobe-hosted Alice PDF](https://www.adobe.com/be_en/active-use/pdf/Alice_in_Wonderland.pdf).
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762).
- [First Woman archive](https://firstwomancomic.com/) — mirror of NASA's comic, not an official NASA host.

Native reproduction flows are in `apps/mobile/flows/compatibility/`. They are ordered, corpus-dependent exploratory capture flows, not an isolated regression suite: import the corpus first, run Haruko CBZ (dismisses the TXT notice), PDFs, Alice EPUB, First Woman, then Japanese EPUBs. Reset saved reading positions before rerunning first-page assertions. Japanese EPUB selectors distinguish duplicate titles by newest-first library ordering. Successful flow completion is not a visual rendering assertion.

## Limits

No Android or physical-device run, frame-time/memory profiling, 10,000-book benchmark, DRM/password prompt tests, CBR/RAR test, exhaustive pagination, or full-book readthrough was performed. This run demonstrates sampled PDF/CBZ compatibility and reproducible EPUB defects; it does not establish production readiness or performance.
